# Research sources

- Google Play target API level requirements (official): https://support.google.com/googleplay/android-developer/answer/11926878 — crawled 2026-08-29; states that starting August 31, 2026, new apps and updates must target Android 16/API 36 or higher for standard Android apps.
- Android Developers target SDK requirements (official): https://developer.android.com/google/play/requirements/target-sdk — confirms Google Play target API timeline.
- Model Context Protocol specification (official): https://modelcontextprotocol.io/specification/2025-06-18 — defines MCP as an open protocol for connecting LLM apps with external data/tools.
- MCP official repository: https://github.com/modelcontextprotocol/modelcontextprotocol — specification, schema, and docs repository.
- OpenAI API docs (official): https://developers.openai.com/api/docs — Responses API supports direct model requests, tools, and multimodal workflows; Agents SDK supports orchestration.
- OpenAI function/tool calling docs (official): https://developers.openai.com/api/docs/guides/function-calling and https://developers.openai.com/api/docs/guides/tools — tool calling, hosted tools, file search, web search, and remote MCP concepts.
- Google Gemini API docs (official): https://ai.google.dev/gemini-api/docs — Gemini API supports text/image generation, multimodal analysis, and agent applications.
- Gemini Live API docs (official): https://ai.google.dev/gemini-api/docs/live-api — preview low-latency realtime voice/vision.
- Gemini text generation docs (official): https://ai.google.dev/gemini-api/docs/text-generation — multimodal inputs include media, documents, video, and audio.
